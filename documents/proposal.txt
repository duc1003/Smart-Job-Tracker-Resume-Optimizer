🧠 Smart Job Tracker & Resume Optimizer
Nền tảng hỗ trợ tìm việc thông minh tích hợp AI (GPT-4)

🔧 Công nghệ sử dụng (Tech Stack)
Frontend: React.js (hoặc Vue.js), TailwindCSS, TypeScript

Backend: Node.js (Express), TypeScript

AI: GPT-4 API (OpenAI)

Database: MongoDB (Mongoose) sau đó phát triển lên mysql

Automation: Puppeteer / Scraper API

Tích hợp: Google API (Calendar, Drive, Gmail), LinkedIn, Indeed

⚙️ Tính năng chính (MVP)
👤 Dành cho người tìm việc
Nhập CV & Job Description (JD)
→ Hệ thống đánh giá mức độ phù hợp giữa CV và JD (dùng GPT-4).

Gợi ý chỉnh sửa CV theo JD
→ GPT đưa ra các gợi ý sửa đổi, thêm kỹ năng, từ khóa liên quan.

Tạo CV từ JD tự động
→ Người dùng chỉ cần dán JD, hệ thống tạo ra một bản CV hoàn chỉnh.

Theo dõi trạng thái ứng tuyển
→ Các trạng thái: Đã nộp, Đang phỏng vấn, Bị từ chối, Được offer.

Nhắc gửi follow-up email
→ Có mẫu sẵn, nhắc người dùng sau 3–5 ngày chưa phản hồi.

🧑‍💼 Dành cho nhà tuyển dụng
Đăng bài tuyển dụng (job post)

Quản lý hồ sơ ứng viên
→ Xem danh sách ứng viên, lọc theo mức độ phù hợp do GPT đánh giá.

Phỏng vấn trước bằng AI (Mock Interview)
→ AI hỏi và chấm điểm dựa trên JD + CV.

🔗 Tính năng tích hợp nâng cao (Mở rộng)
Tính năng	Mô tả
Google Calendar	Tự động thêm lịch phỏng vấn vào Google Calendar
Google Drive	Lưu trữ các CV và JD theo dạng thư mục
Gmail API	Gửi CV trực tiếp qua email, nhận thông báo phản hồi
LinkedIn/Indeed Integration	Import job mới mỗi ngày qua scraper hoặc API
Gợi ý job phù hợp	AI dựa vào nội dung CV để gợi ý job từ nguồn LinkedIn/Indeed
Dashboard thống kê	Timeline, Heatmap theo dõi quá trình ứng tuyển, thời gian phản hồi, tỉ lệ nhận job
Bộ CV chuyên biệt	Người dùng có thể tạo nhiều CV theo từng JD khác nhau
