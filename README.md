# Smart Job Tracker & Resume Optimizer

Một nền tảng tìm việc tích hợp GPT-4, giúp người dùng tối ưu CV, theo dõi tiến trình ứng tuyển và kết nối trực tiếp với nhà tuyển dụng.

---

## Tính năng chính

- Đánh giá độ phù hợp giữa CV và Job Description bằng AI
- Gợi ý sửa CV hoặc tạo CV từ JD (GPT-4)
- Theo dõi trạng thái ứng tuyển
- Tạo email follow-up tự động
- Nhà tuyển dụng đăng job, nhận CV
- Tích hợp Google Calendar, Drive, Gmail
- Scrape job từ LinkedIn / Indeed

---

## Công nghệ

- Frontend: React.js / Vue.js + TypeScript
- Backend: Node.js (Express)
- AI: OpenAI GPT-4
- Database: MongoDB
- Tích hợp: Google API, Puppeteer / ScraperAPI
